# Mr. Service Executor

Webの6 Service Cell（18 variant）の依頼を、本人のMacのCodexで処理し、成果物を同じWebへ返す実行担当です。外部APIキーをWebに置かず、Codexの認証情報も転送しません。Codexの利用枠、端末の電力・通信を使用します。常駐サービスの自動インストールや課金開始は行いません。

## 本人の端末を接続する

Node 22.13以上、対応するCodex CLIとそのログイン、macOS Keychain、最新Mr.が必要です。公開Webへ新コードが反映されてから接続します。

1. Webの「仕事・収支」→「サービス」→「実行端末の接続コードを作る」。
2. Mr.のフォルダで以下を実行し、求められたら本人専用コードを貼り付けます。入力は非表示で、コードをコマンド引数や履歴へ入れません。

```sh
node services/service-executor/cli.mjs connect https://life-manager-one-hub.kirin-999.chatgpt.site
node services/service-executor/cli.mjs start
```

生成による接続確認が成功するとWebは「実行可能」になります。6サービスを選択し、個別に依頼します。進捗と結果は約8秒おきに更新。端末を閉じる・スリープすると処理できません。Ctrl+Cで停止、Webの「端末を切断」で鍵を失効できます。切断・再発行はその本人の実行待ち・処理中の依頼を停止扱いにします。すでに開始したモデル処理は終了まで計算が続く場合がありますが、取消後の結果は受理しません。

接続設定`.mr-executor.json`は非秘密のURLとKeychain参照名だけでGitから除外します。コードはKeychain、WebにはSHA-256ハッシュだけを保存。1アカウントにつき現在1つの接続鍵です。他人へ共有しないでください。

## 実行範囲

- CREATE: 台本・記事本文、タイトル、撮影キュー。
- GROW: 提供情報からのSEO仮説・キーワード候補・構成。検索量や順位は実測しません。
- LAUNCH: 単体HTML/CSSのコード本文。ブラウザーで実行・公開しません。
- SELL: 商談返信・見積り・提案の下書き。
- LEARN: 提供された顧客記録のテーマ・根拠・仮説。
- DELIVER: 提供された要件と成果物テキストの照合。実画面・バイナリファイル・URL先の検査ではありません。

txt/md/json添付はUTF-8・64KBかつ16,000文字まで。PDF・画像は受付時に拒否し、読んだふりをしません。AI生成物は本人の確認が必要です。公開、投稿、外部納品、決済、収益発生は別操作です。

## 安全境界と運用

- 接続コードは他の利用者の仕事を取得できません。削除世代と失効をサーバー側で照合します。
- 一人1時間10件・同時受付3件。端末の応答が60秒ないと新規実行を止めます。
- 一回のモデル処理は4分、取得leaseは5分。期限切れは失敗とし、重複課金を避けるため自動再実行しません。再依頼は本人が内容を確認して行います。
- 起動時の生成検査は1回の実際のモデル利用です。合格しない限り実行可能にしません。
- 既存のqueued履歴は自動移行・実行しません。新しい同意付き受付だけを処理します。
- 成果物は構造・長さを検証してD1へ保存。再送は同じclaimに対する同じ結果だけを受理。result保存直後の障害も再表示時に修復します。
- 実行中の取消は結果保存を拒否。Hubデータ削除は実行結果と接続鍵も対象にします。外部のCodexサービス側の保持・削除とは別です。
- 子プロセスは空の一時フォルダ、read-only、利用者設定・接続プラグイン・シェル・ブラウザー・外部ツールを無効化。環境変数は最小限にし、出力にtool-callが出た場合も失敗にします。生の診断ログやプロンプトをWebへ返しません。

[Codex公式の設定リファレンス](https://learn.chatgpt.com/docs/config-file/config-reference)とローカルCLIの対応設定に基づき、実行権限を制限しています。CLI更新時は実生成テストを行ってください。

## 検証

```sh
node --test services/service-executor/worker.test.mjs
node services/service-executor/cli.mjs check
```

2行目は実際のCodex枠を使います。自動CIはmockを使い、実モデル・本番サービスを呼びません。`scripts/smoke-service-execution.mjs`は明示実行専用で、localhost限定のHTTP/D1と実モデルを使い、6種類の成果物・冪等性・再表示を確認して試験行だけを掃除します。
