# MCP Bot Hub 特許戦略サイト

複数BOT・MCP・APIを一つの操作から起動し、成果を検証して報酬を分配する構想を、先行技術調査・弁理士相談用に整理したSitesプロジェクトです。

## 役割

- 発明候補の技術構成、Amazon 1-Clickとの差、請求項候補、実装証拠を説明する
- 「ワンクリック」という抽象アイデアではなく、権限、依存関係、冪等実行、外部readback、成果帰属、分配までの具体的構成を保存する
- `public/MCP_Bot_Hub_特許戦略メモ.pdf`を配布する

## 注意

- 特許取得済みという意味ではない
- 公開前に新規性・進歩性・出願順序を弁理士へ確認する
- Bot token、API key、顧客データは保存しない

## 確認

```bash
npm install
npm run build
```
