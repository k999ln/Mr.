# 情報保存とクリーンアップ運用

この文書は、ChatGPT上の会話・MCP接続・プラグイン・スキル・ローカル作業を整理するときの安全基準です。

## 正本

- 作業再開時は[プロジェクト索引](../PROJECT_MEMORY_INDEX.ja.md)を最初に読みます。
- 事業・設計・実装の正本は、確認済みのGitHubリポジトリと、その中のドキュメントです。
- 公開サイトは成果物であり、正本ではありません。公開版のURL・Sitesのversion・Git commitを記録します。
- ローカルの未コミット変更、未追跡ファイル、認証情報、外部アカウントの状態は、バックアップと確認が終わるまで削除しません。

## 削除前チェック

次のすべてを満たすものだけ整理対象にします。

1. GitHubまたは明示的なバックアップに保存されている。
2. 保存先のcommit、ファイル一覧、ハッシュまたはバックアップ日時を確認できる。
3. 未コミット差分、未追跡ファイル、秘密値、決済・アカウント設定を含まない。
4. 現在のアプリ、MCP、スキル、プラグインが参照していない。
5. 削除対象と復元先を記録している。

1つでも不明なら、削除せず「保留」として残します。

## 定期監査の対象

- Gitの未コミット・未追跡状態
- リモートとの差分と最後のpush
- Sitesの公開versionとproduction URL
- `AGENTS.md`、`project.md`、`config/owner-public.json`、運用手順
- MCP接続先、リポジトリ、プラグイン、スキルの参照切れ
- バックアップの存在と復元可能性

## ChatGPTの整理について

`/doctor`、`/compact`、`/clear`はこのエージェントから直接実行できません。代わりに、上記の監査を実施してから、保存済みの事実だけを短いインデックスに集約します。会話の要約・削除であっても、未保存の判断や認証情報を新たに記憶へ移したことにはしません。
