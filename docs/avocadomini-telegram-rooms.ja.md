# avocadomini Telegram 総合司令室・道具別ルーム設計

## 目的

サイトで道具を選んだ後に名前を再表示するだけではなく、利用者が「これは何か」「何を送ればよいか」「何が返るか」「どんな通知が来るか」をTelegram内ですぐ理解し、そのまま仕事を始められる状態にする。

## Telegram上の形

TelegramのBotとの個人チャットには、Botが複数のグループやForum Topicを自動作成する機能はない。そのため、Kai所有の単一Bot・単一個人チャットを維持し、メッセージとボタンを切り替える仮想ルームとして提供する。

- **総合司令室:** 選択中の道具、自然文の依頼、今日やること、10種類一覧、追加・変更、使い方の入口。自然文は選択中の1〜3種類だけを組み合わせ、必要な場合だけ未選択の道具を1つ提案する。自動追加はしない。
- **道具別ルーム:** 道具の説明、入力するもの、返るもの、通知、最初の一歩、具体例、「この道具に頼む」。
- **仕事Job:** 依頼、状態、成果物、修正元、Telegram結果message ID、利用者の完了操作を保存する。
- **通知:** 同じ個人チャットへ道具名つきで送り、結果から「修正する」「完了にする」「総合司令室」を選べる。

将来、利用者が自分で作ったTelegram SupergroupへBotを管理者として追加した場合に限り、Forum Topicを物理的な部屋として使う拡張は可能。ただし初回設定が増えるため、標準導線にはしない。

## 初回導線

### サイトで1〜3種類を選んだ人

1. サイトの選択を保存する。
2. 再同意、再選択、法律ページへの誘導を挟まない。
3. 選択した道具だけを並べた総合司令室を直接開く。
4. 各道具のボタンから説明と使い方を確認し、「この道具に頼む」へ普通の文章で返信する。

### Telegramへ直接来た人

1. 「仕事内容からおすすめ」か「10種類から自分で選ぶ」を選ぶ。
2. 仕事内容は、作品・発信、講師・コーチ、相談・代行、店舗・商品、チーム販売、未定の6種類。
3. おすすめ3種類を仮選択する。本人は1〜3種類へ自由に変更できる。
4. 「この内容で始める」で保存し、総合司令室を開く。

## いつでも戻れるコマンド

ボタンを見失っても、次の5つはどの画面からでも使える。BotFatherのコマンド一覧もこの内容だけを表示し、旧設定コマンドと混ぜない。

| コマンド | 開く場所 |
|---|---|
| `/home` | 最新の選択を読み直して総合司令室を開く |
| `/tools` | 10種類の説明、現在の選択、追加・変更を開く |
| `/jobs` | 仕事内容からおすすめを選ぶ |
| `/today` | 受付中、作業中、結果お届け済み、完了、失敗を確認する |
| `/help` | 初め方と上記の入口を表示する。データベースが一時的に読めなくても説明自体は表示する |

`/start`は初回開始または前回の総合司令室の復元に使う。Core起動時に、Webhookだけでなく上記のBotFatherコマンド一覧と説明文も公式APIで照合し、違う場合だけ自動修復する。

## 10種類の責務

| 道具 | 主な役割 | 代表的な入力 | 代表的な出力・通知 |
|---|---|---|---|
| 依頼を整理 | 相談を実行手順へ変える | 目的、期限、困りごと | 優先順位、確認待ち、期限 |
| 教材を作る | 知識を教材へ構成する | 対象者、内容、形式 | 構成、本文、完成通知 |
| 内容を検証 | 根拠と抜けを点検する | 文章、URL、商品案 | 根拠、注意点、修正案 |
| 売り場を作る | 商品と販売ページを作る | 商品、価格、販売相手 | 商品下書き、公開承認待ち |
| 集客を広げる | 集客案と投稿を作る | 商品、相手、期間、媒体 | 投稿案、配信計画、結果 |
| 見込み客を育てる | 段階的な案内を作る | 相手の悩み、商品、連絡手段 | 案内文、返信、フォロー時期 |
| 入金を確認 | お金の状態を確認する | 商品、注文、期間 | 入金、失敗、返金、要確認 |
| 商品を届ける | 購入後の納品を管理する | 注文、提供物、条件 | 納品待ち、完了、失敗 |
| 成果を測る | 数字を改善案へ変える | 期間、商品、目標 | 要約、目標差、改善候補 |
| 報酬を分ける | 共同販売の分配を整理する | 売上、相手、割合 | 分配案、確認待ち、支払い記録 |

## 実行と安全

- 下書き、整理、説明はチャットから開始できる。
- 公開、外部送信、一斉配信、決済、返金、送金は、対応する接続先と実行機能が準備でき、利用者が内容を確認した場合だけ行う。
- 接続がない機能は成功したように見せず、必要な接続または準備中であることを表示する。
- 無料選択は1〜3種類であり、必ず3種類を選ぶルールではない。
- サイトの機能10種類と、Telegram・Stripe・Emailなどの外部接続サービスを同じ「道具一覧」として混ぜない。

## 画面状態

```text
直接 /start
  ├─ 仕事内容からおすすめ ─┐
  └─ 10種類から選ぶ ──────┴─ 選択（1〜3）─ 総合司令室

サイトから /start f2_...
  └─ 選択保存 ───────────────── 総合司令室

総合司令室
  ├─ 普通の文章 ─ 司令Job（選択中の1〜3道具を組み合わせる）─ 結果 ─ 修正／完了
  ├─ 選択中の道具別ルーム
  │    └─ この道具に頼む ─ 自然文 ─ Job受付 ─ 結果 ─ 修正／完了
  ├─ 今日やること（同じJob正本から再開）
  ├─ 10種類一覧
  ├─ 道具を追加・変更
  └─ 使い方
```

## 合格条件

- 10種類すべてに説明、入力、出力、通知、具体例がある。
- 10種類すべてで自然文を永続Jobとして受付できる。
- 総合司令室へ直接送った自然文も、選択中の道具だけを使う永続Jobとして受付できる。
- サイト選択者へ同意・再選択を表示しない。
- 選択済み利用者の`/start`は、データベースの最新選択から総合司令室を復元する。
- 直接利用者がTelegramだけで1〜3種類を選択・保存できる。
- 各ボタンの`callback_data`がTelegram上限64 bytes以内。
- 保存に失敗した場合は総合司令室を開かない。
- 同じTelegramメッセージを二重Job化せず、別利用者はJobを修正・完了にできない。
- 完了ボタンを再送・連打しても完了通知を二重送信しない。
- 「今日やること」はCommerceの別状態ではなく、道具別Jobの状態を表示する。
- `/home`、`/tools`、`/jobs`、`/today`、`/help`がボタンと同じ最新状態を開き、旧コマンド画面へ迷い込まない。
- Core再起動時にBotFatherのコマンド一覧・説明を照合し、差分があれば更新後のreadbackまで行う。
- 外部実行は既存の承認・接続・readback方針を維持する。
